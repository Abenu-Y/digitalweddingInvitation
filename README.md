# 💍 Hosni & Jerusalem | Royal Wedding Digital Invitation (የሰርግ ጥሪ)

A royal, interactive digital wedding invitation web application built with **Next.js 14**, **Tailwind CSS**, and **Framer Motion**, tailored for Ethiopian Habesha cultural elegance.

---

## ✨ Features

- **Royal Save-The-Date & Invitation Cards**:
  - Save the Date card with Ge'ez and English typography and biblical scripture (Psalm 13:5 / መዝሙረ ዳዊት 13:5).
  - Our Invitation story message from Hosni & Jerusalem.
  - Ethiopian Calendar card (ህዳር 6፣ 2019 ዓ.ም / November 15, 2026).
- **Auto-Scroll Experience**:
  - Smooth, automatic glide down with natural reading pace.
  - Quick **Pause (`||`)** and **Play (`▶`)** toggle controls.
  - Pause-on-hold and resume seamlessly.
- **Embedded Interactive Google Map**:
  - Ceremony venue card and interactive Google Maps embed for **Lideta Mekane Yesus Church, Addis Ababa**.
- **Simplified RSVP System**:
  - Affirmative attendance response with instant confetti celebrations.
- **Wishes Guestbook Wall**:
  - Interactive blessings and congratulations wall for friends and family.
- **Couple Admin Portal (`/admin`)**:
  - Discreet access gate with Username & 6-Digit OTP security.
  - **Auto-Scroll Speed Controls**: Preset buttons (`Slow`, `Natural`, `Moderate`, `Fast`, `Turbo`), step buttons (+/- 5), and direct numeric input in px/sec.
  - **Themes & Styles Manager**: 6 Habesha luxury themes (Emerald Velvet, Habesha Gold, Royal Burgundy, Midnight Obsidian, Rose Quartz, Pearl Ivory).
  - **Zero Browser Popups**: Sleek, custom in-app confirmation modals and toast notifications.
  - **Language Toggle**: Clean English by default with optional Amharic switch (`[English | አማርኛ]`).

---

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the wedding invitation.

---

## 🛠 Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS, Vanilla CSS animations
- **Animation**: Framer Motion, Canvas Confetti
- **Icons**: Lucide React
- **Language**: TypeScript
